#+TITLE: Serita
#+SUBTITLE: Reads and writes Org files

Serita is an Org-mode app for phones, tablets, Chromebooks and desktop browsers. It is MIT licensed and written from scratch.

* Use
Open the app in a browser and install it from the browser's menu; it then starts offline.

The toolbar has Files and Save at the left, Find in the middle, and View and Menu at the right. Each file is a tab; the × closes it. Saving is manual.

** Files
- New :: opens a ~*scratch*~ buffer.
- Open :: picks a file from app storage, GitHub or WebDAV, with its size. Under Change, Device files opens your device's own file picker.
- Save :: writes the current tab to its file.
- Save as :: writes it to another storage or name; with Device files, your device's save dialog opens.
- Save some buffers :: asks about each unsaved tab: Yes, No, Save all or Cancel.
- Keep files offline :: in the Commands palette, lists your GitHub and WebDAV Org files; turn one On and Fetch now saves it, so it opens, and the agenda reads it, without a connection. Requests give up after 8 seconds.

** Views
View switches between Outline and Text; both show the same document and the same folding.

The Outline view lists headings as a tree. The arrow at the left of a heading cycles its visibility, like TAB in Emacs: folded, children, whole subtree. Tap a TODO word to change its state, a checkbox to toggle it, and a heading's title for its actions. The values that are set show as chips (state, priority, scheduled, deadline, tags, effort) that you tap to change; + Add lists what is not set, plus Property, Clock in and Timestamp. Below are Text (edit the title or the body) and Structure (promote, demote, the subtree, move, insert a heading below, refile, archive, cut or copy the subtree, and paste the last one after this subtree at its level). Edit title and Insert heading below open a popup with a text field, where Enter accepts it; Edit body opens a larger field for the text under the heading.

A checkbox toggles when you tap it. The checkbox of the item above it, and the ~[2/4]~ or ~[50%]~ counts of that item and of the heading, follow. A list item folds with its arrow, like a heading.

The Text view shows the raw Org text, with ~...~ after a folded heading. A file's ~#+STARTUP:~ line sets what is folded when it opens; without one, everything is shown.

** Emacs keys
Settings, Emacs, Emacs keys, turns on these keys in the Text view:
- TAB :: cycles the heading or list item at the cursor; S-TAB cycles the whole buffer: overview, contents, show all.
- M-up, M-down :: move the subtree, or the list item with its sub-items, up or down.
- M-left, M-right :: promote or demote the heading; on a list item, change its indentation and leave its sub-items; with Shift, the whole subtree or the sub-items too.
- C-RET :: inserts a heading after the current subtree, from the heading or anywhere in its body.
- C-c C-x C-w, C-c C-x M-w, C-c C-x C-y :: cut, copy or paste a subtree (in a table they work on cells). A number before C-w or M-w takes that many sibling subtrees. Paste at the start of a heading puts the subtree before it, at that heading's level; anywhere else it goes after the subtree the cursor is in. A number before C-y sets the level. Palette: ~org-cut-subtree~, ~org-copy-subtree~, ~org-paste-subtree~.
- C-n, C-p :: move down or up one screen line, keeping the column; C-f, C-b move a character; C-a, C-e go to the start or end of the line; M-f, M-b move a word; M-<, M-> go to the start or end of the text; C-v, M-v move a screen down or up. On plain text M-right moves a word.
- The text scrolls to keep the cursor in view after any movement or search, and puts the cursor in the middle of the screen when it was off screen.
- C-g :: quits a pending key or command. Errors and quits give a short beep (Settings, Emacs, Beep on errors).
- C-s, C-r :: search forward or backward; again inside the search, the next or previous match; on an empty field, the last search. C-g or the cancel button returns to where you started.
- C-c C-t :: changes the TODO state, from the heading or anywhere in its body. S-right and S-left go to the next or previous state; the parent's ~[2/4]~ count follows.
- S-up, S-down :: raise or lower the priority of the heading. C-c , asks for it: A, B, C, or SPC to remove.
- C-c C-x p :: sets a property: asks for the name, then the value. The drawer is created when needed and starts folded. M-x org-delete-property removes one.
- C-c C-q :: sets the tags.
- M-x :: runs a command by name. Type any words of the label or name; TAB completes, RET runs.
- C-c C-c :: toggles the checkbox on the line; on a ~[/]~ or ~[%]~ cookie it recounts it.
- M-RET, M-S-RET :: on a list item, start a new item (M-S-RET with a checkbox): above the item when the cursor is at the start of its text, otherwise the line breaks at the cursor and the rest becomes the new item. Numbered lists renumber.
- RET :: in the text of a list item (Emacs keys on), breaks the line and indents the new one to the item's text. S-LEFT and S-RIGHT anywhere on an item's first line change the list's bullet as C-c - does; elsewhere off a heading and a timestamp they select nothing and say so, unless ~org-support-shift-select~ is ~t~ in the settings file.
- C-c - :: on a list item, changes the bullet of the whole list to the next kind (-, +, 1., 1)); a number prefix picks the kind (0 is -, 1 is +, and so on; an indented list also has *). On a line of text or a heading, or on selected lines, it makes items.
- C-c * :: turns an item or a line of text into a heading one level below the heading above, and a heading into text.
- C-c ^ :: sorts the list the cursor is in: alphabetically, numerically, by time or by checkbox; a capital letter reverses. In a table it sorts the lines.
- C-u C-c C-c, C-u C-u C-c C-c :: on an item add or remove a checkbox, or set it to ~[-]~. C-c C-c on an item with no checkbox renumbers the list. M-x org-list-repair does the same.
- M-RET :: starts a heading at the cursor: above a heading when the cursor is at its start, below it at its end, and in other text the line breaks there and the rest becomes the heading.
- C-/, C-_, C-x u :: undo; C-? redoes.
- C-k :: kills to the end of the line, then the line break; consecutive kills join. C-S-DEL kills the whole line, and C-y yanks the latest kill.
- M-g g :: goes to a line. C-x h selects everything.

To type C-c or C-x, use Ctrl on the key row and then the letter; a keyboard's own C-c and C-x still copy and cut.

Above the mode line, a row of keys stands in for a keyboard: Meta, Ctrl and Shift apply to the next key, and a letter typed on the on-screen keyboard after Ctrl or Meta is the key chord, for example Ctrl then n is C-n. Tab and the arrows follow; the arrows move as C-p, C-n, C-b and C-f do, and with Shift they extend the selection. The keyboard button shows or hides the on-screen keyboard. Float turns the row into a panel you can drag; Dock puts it back. Pressing a key never opens the keyboard.

Settings, Debugging, Record key events, records what the keyboard sends and which key chord Serita made of it. Turn it on, press the keys in the editor, then open Debugging again to read the log, Copy it or Clear it; it helps when a key does not do what it should.

Settings, Emacs, Hide leading stars, shows only the last star of each heading. Indent files on open turns on org-indent-mode: each level is indented two columns and the text under a heading lines up with the heading's text, with nothing added to the file. A file can ask for it with ~#+STARTUP: indent~ or refuse with ~#+STARTUP: noindent~, and the palette command Indent mode toggles it for the file you are in. Both apply to the Text view; the Outline view always shows every star and its own indentation.

** Tool row
Under the tabs, one row of buttons: undo, redo, line numbers, wrap, smaller text, larger text, and Line. Settings, Appearance turns the row on or off for each view. In the Outline view the row keeps undo, redo and the two size buttons. Line opens Lines and text: go to a line, select all, copy all, duplicate, delete (to the kill ring), move, indent and outdent the line. Typing within a second is one undo step; each structure edit is its own.

** Appearance
Menu, Settings, Appearance: Theme (System, Light or Dark), Font (monospace by default, or another, or a font name from your device), Font size (12 to 32; A− and A+ change the same size) and Paragraph spacing (0 to 32 px, Outline view), the Tool row of each view, and the Tables settings: Wrap table cells, Table width and Stripe table rows. Menus and buttons keep a fixed size.

** Tag column
Menu, Settings, Emacs, Tag column. A negative number ends the heading line at that column (-77 by default); a positive number starts the tags there; 0 puts them one space after the title.

** Restore
Open files, the current tab, folds, the view and unsaved edits come back when you reopen Serita. Settings, Emacs, Restore open files on start turns it off.

** Back
The arrow at the bottom left of the text goes back to where you came from: a place you left by tapping a tab, a row of the agenda, Go to line, a search, or M-< and M->. After an agenda row it returns to the agenda. Hold it to see where it would go. C-x C-SPC does the same.

** Swipe
Swipe a heading in the Outline view from right to left to fold or unfold it, like TAB.

** Minibuffer
In the Text view, questions are asked on the line at the bottom, as in Emacs: the prompt sits in the field, RET accepts and C-g or Esc cancels. The buttons ✓ and ✕ do the same by touch. Completions appear above the key row.

In the Outline view, the same questions are touch dialogs. Menu, then Commands, lists the commands that work without a cursor, with their Emacs names and keys; type to narrow the list. The row at the bottom gives the next command a universal argument (see below).

** Universal argument
C-u multiplies the argument of the next command by four, and C-0 to C-9 or C-- give it a number. In the Outline view, Menu, then Commands, has a C-u button that counts up (C-u, C-u C-u, C-u C-u C-u, then off) and a row of digits beside it; the line above says which prefix the next command will use.

- C-u C-c C-w :: only visits the target; C-u C-u goes to where the last refile put its subtree; C-3 keeps the entry; C-0 or C-u C-u C-u clears the refile cache.
- C-u TAB :: cycles the whole buffer; C-u C-u TAB shows the startup visibility, C-u C-u C-u TAB everything. C-2 S-TAB shows the headings down to level 2.
- C-3 C-c C-t :: sets the third TODO keyword; C-u C-u C-c C-t switches to the next keyword set.
- C-u M-RET :: inserts the heading after the subtree; C-u C-u M-RET at the end of the tree above.
- C-u C-c - and C-u M-S-down :: insert the rule above and the row below. C-c ^ f sorts with a function: upcase, downcase, capitalize, identity, length, string-to-number or string-trim to extract the key, and string<, string>, <, >, <= or >= to compare.
- C-u C-c , :: shows the priority as a number.

** Find
Type to search. The prompt shows ~I-search:~, ~Wrapped I-search:~ or ~Failing I-search:~. The match is highlighted; ▲ and ▼ go to the previous and next match. Past the last match the search fails; one more press wraps. C-s on an empty field recalls the last search. A lowercase query ignores case; an uppercase letter makes it exact. Return keeps the cursor on the match, and × returns to where you started.

** Regexp search
C-M-s and C-M-r search forward and backward for an Emacs regexp; M-r inside a search switches between plain and regexp. The prompt reads ~Regexp I-search:~.

** Replace
M-% replaces text; C-M-% replaces a regexp (\& is the match, \1 a group, \# the count). Answer each match with y or SPC (replace), n or DEL (skip), ! (replace the rest), . (replace and stop), q or RET (stop), ^ (back). A replacement follows the case of the match unless the search has a capital. On a touch screen each key has a button. Example: M-% ~cat~ RET ~dog~ RET, then ~!~.

** Sparse trees
C-c / r shows the lines that match a regexp and the headings above them; C-c / t shows unfinished TODO entries; C-c / T asks for a keyword; C-c / m asks for a match such as ~work+urgent~, ~work-{^h}~ (a regexp over the tags), ~work/TODO~, ~/!~ (unfinished TODO), ~LEVEL=2~, ~PRIORITY="A"~ or ~Effort="5h"~ (tags are inherited). C-c / d shows the deadlines that are past due or due within 14 days. C-c / b, C-c / a and C-c / D ask for a date (or two) and show the entries whose SCHEDULED or DEADLINE date is before it, on or after it, or from the first date up to but not including the second. A regexp for C-c / r may span lines. C-c C-c removes the highlights; TAB folds the heading. In the Outline view, Menu, then Commands has the same entries.

** Tables
In the Text view, with the cursor in a table: TAB aligns the table and moves to the next field (a new row at the end), S-TAB to the previous; RET moves to the next row; S-RET copies the field above (numbers and dates count up); M-RET splits the field at the cursor. M-up and M-down move the row; M-left and M-right move the column; M-S-up deletes the row and M-S-down inserts one; M-S-left deletes the column and M-S-right inserts one. C-c - adds a horizontal line, C-c RET adds one and moves below it, C-c C-c aligns, C-c ? shows the field's coordinates.
C-c ^ sorts the rows between horizontal lines by the column: a, n or t for alphabetic, numeric or time order, a capital letter for the reverse. C-c | asks for a size such as ~3x4~ and makes a table; with text selected it turns the lines into rows. Palette: ~org-table-transpose-table-at-point~, ~org-table-sort-lines~, ~org-table-align~, and each row and column command by name (~org-table-kill-row~, ~org-table-insert-row~, ~org-table-move-row-up~, ~org-table-delete-column~, ~org-table-insert-column~, ~org-table-move-column-left~ and the others), for a keyboard without Meta.
C-c C-x M-w copies the cells between the two ends of the selection, C-c C-x C-w cuts them, and C-c C-x C-y pastes them from the field at the cursor, adding rows and columns as needed. C-# turns the mark in the row's first column from blank to ~#~ to ~*~ and back. With marks present, a column formula reaches only the rows marked ~#~ or ~*~ when the whole table is recalculated; TAB, S-TAB, RET and C-c C-c first recalculate a row marked ~#~, and C-c * skips rows marked ~!~, ~^~, ~_~, ~$~ or ~/~. With text selected, C-c | turns it into a table, splitting at tabs, commas or spaces as Emacs guesses. Palette: ~org-table-export~ (also Export in the Outline view's table sheet) shows the table as csv, tsv, orgtbl, generic, LaTeX, HTML, Texinfo or Unicode text to Copy or Save (LaTeX, HTML and Texinfo turn Org markup in the cells into each format's own: ~*bold*~, ~/italic/~, links, entities such as ~\alpha~, ~x_1~ and ~x^2~); ~org-table-import~ takes pasted text or a chosen file and turns it into a table at the cursor.
In the Outline view a table is a grid. Tap a cell for its sheet: edit the cell, change its row or column, or sort by it. A width cookie such as ~<10>~ shortens what the grid shows, not the text. In Settings, Emacs: Wrap table cells (~org-table-widget-wrap-columns~) wraps long cells so rows grow taller, Table width (~org-table-widget-max-width-fraction~) sets how much of the screen a table may use, and Stripe table rows (~org-table-widget-zebra-stripe~) shades every other row. With wrapping on, a width cookie sets that column's width and its text wraps inside it.

** Table formulas
A ~#+TBLFM:~ line directly under a table holds its formulas, separated by ~::~. ~$3=$1+$2~ fills column 3 below the first rule; ~@5$3=vsum(@I..@II)~ sets one field. In an expression ~$N~ is a column, ~@N~ a row, ~@<~ and ~@>~ the first and last rows, ~@I~ a horizontal line, and ~a..b~ a range. Flags follow a semicolon: ~;%.2f~ formats, ~;N~ reads text as 0, ~;T~ and ~;t~ show times, ~;D~ and ~;R~ choose degrees or radians, ~;F~ keeps fractions. A row starting with ~!~ names its columns, ~_~ names the fields below it and ~^~ the fields above, and ~$name~ then stands for them. ~;E~ makes an empty field ~nan~, so the result is ~nan~. ~remote(name,@1$2)~ reads a field or range of the table named by a ~#+NAME:~ line above it, and a ~$~ row holds ~name=value~ parameters. A field that starts with ~=~ becomes the column's formula when you press C-c C-c in it. A name Calc does not know stays as it is and is simplified like Calc does (~x+x~ is ~2 x~); ~a mod n~ is a modulo form. Calculations are exact for integers and fractions written ~1:2~, and 12 digits otherwise; ~2#101~ and ~16#ff~ are numbers in another base, and a formula starting with ~'(~ is Lisp.
C-c C-c on a ~#+TBLFM:~ line recalculates the table. C-c * recalculates the row, C-u C-c * the table, C-u C-u C-c * until nothing changes. In formulas, units are names: ~5 m + 3 m~ is ~8 m~, and ~usimplify(1 km + 200 m)~ gives ~1.2 km~. ~uconv(2.5 km, ft)~ converts (8202.0997 ft; a third argument such as ~t~ drops the unit; units that do not match give base units). Like ~u c~ in Calc it converts a temperature as a difference, so ~uconv(100 degC, degF)~ is 180 degF; ~utemp(100 degC, degF)~ gives the reading, 212 degF. ~expr => x~ shows the formula and its value, such as ~1+2 => 3~ in the field. Distance, weight, volume, speed, pressure, energy, power and time units are known (Calc's names: km, mi, ft, kg, lb, oz, L, gal, mph, atm, psi, kWh, hr...). C-c = sets the column's formula, C-u C-c = the field's; an empty answer removes it. C-c ' edits all of the table's formulas in one sheet, one ~$3 = $1+$2~ per line. C-c } shows row numbers, and on each horizontal line its number and the column numbers, on the tables of the Outline view, C-c { turns formula debugging on or off: while it is on, each field a recalculation sets first shows how its formula was read and calculated, and you Continue or Stop. Both start off in each session. C-c " g plots the table: the chart opens in a sheet, and Save image keeps it as SVG. Options go on a ~#+PLOT:~ line above the table, such as ~title:"Sales" ind:1 deps:(2 3) with:lines~; ~with~ is lines, points, linespoints, boxes, histograms, impulses, steps, dots or filledcurves; ~type:grid~ draws the table's numbers as a heat map and ~type:3d~ as a surface you drag to turn; and ~set:~ takes xlabel, ylabel, xrange, yrange, grid and key off. In the Outline view tap a cell, then Plot. C-c + sums the column. Palette: ~org-table-recalculate-buffer-tables~ recalculates every table once, ~org-table-iterate-buffer-tables~ repeats that until the file stops changing (at most 10 times). In the Outline view tap a cell, then Recalculate or Formulas. Example: ~| 2 | 3 |  |~ with ~#+TBLFM: $3=$1*$2~ gives 6. The examples file ~tables.org~ has more.
** Links, footnotes and emphasis
C-c C-o follows the link at the cursor, or the links in the entry when the cursor is elsewhere (a list of them when there are several); in the Outline view a link shows its description and a tap follows it. C-c & goes back. Links to a heading (~[[*Heading]]~), a custom ID (~[[#id]]~), text or a target in the file, ~file:~ names with ~::*Heading~, ~::#id~, ~::12~ or ~::/regexp/~, ~id:~ (found in the open files and the agenda files), ~http:~, ~https:~, ~mailto:~ and ~doi:~ open; ~elisp:~ asks first and runs a small Lisp; ~shell:~ asks first, then says a browser cannot run it; a radio target (~<<<name>>>~) turns every matching word of the file into a link to it; a link that finds no heading offers to create one. A ~file:~ name is relative to the file you are in. A radio target's words match across a line break too.

C-c l stores a link to the heading at the cursor (to its ~:ID:~ with ~org-id-link-to-org-use-id~); C-c C-l inserts the last stored link or one you type, with a description, or edits the link at the cursor; with text selected the text becomes the description. C-u C-c C-l asks for a file and C-u C-u C-c C-l writes its full name. ~org-link-abbrev-alist~ shortens links such as ~gh:foo~.

C-c C-x f adds a footnote at the cursor, with its definition under a Footnotes heading (~org-footnote-section~), or jumps between a reference and its definition. C-u C-c C-x f asks for s (sort the definitions by their references), r (renumber), S (both), n (normalize: every footnote numbered, in one place) or d (delete). C-c C-x C-f wraps the selection in a marker you choose (asterisk, slash, underscore, equals, plus or tilde); SPC takes one off. In the Outline view emphasis shows styled with its markers; in the Text view links are underlined. Example: ~links.org~.

** Dates
C-c C-s schedules the heading and C-c C-d sets its deadline; C-c . inserts a timestamp and C-c ! an inactive one; on a timestamp they change it instead (the prompt starts from its date, a repeater stays, a time or range goes). The prompt takes a date (~2026-12-01~, ~dec 5~, ~12/5~, ~fri~ (the next Friday after today), ~+3d~, ~-1w~, ~+2fri~; a date that has gone by means next year) with an optional time (~14:30~, or a start and its length, ~14:30+1~ or ~14:30+1:25~); empty means today, or the date already set when you schedule or set a deadline on a task that has one. In the Outline view the prompt also shows a month to tap, steppers for the hour and the minutes, and a No time switch. S-up and S-down on a timestamp change the part under the cursor: year, month, day (or weekday), hour, minute, or a repeater's number or unit; on either bracket they switch between active and inactive. S-left and S-right move the date a day. Marking a task with a repeater (~+1w~, ~++1w~, ~.+1w~) DONE moves its date to the next one, on a SCHEDULED or DEADLINE line or on any active timestamp in the entry, and keeps it open.

** Clocking
C-c C-x C-i starts a clock on the heading: a ~CLOCK:~ line in its ~:LOGBOOK:~ drawer. C-c C-x C-o stops it and records the time spent; C-c C-x C-q cancels it. Clocking in on another heading stops the running clock first.

** Effort
C-c C-x e asks for the effort of the heading and sets its ~Effort~ property: ~2:00~, ~2h~, ~30min~ or ~1d~. An empty answer leaves the property empty.

** Agenda files
The agenda covers the files on the agenda files list, not the tabs that happen to be open; a file that is open shows its current text. C-c [ puts the current file on the list and C-c ] takes it off; Settings, Emacs, Agenda files shows the list and adds files from any storage. The list is saved as ~org-agenda-files~, the way an ~init.el~ would set it.

** Agenda
View, then Calendar, shows a month with up to three small squares under each day: green for a birthday, yellow for a holiday, blue for anything else; tap a day to list its entries, and Agenda opens that day in the agenda. Settings, Emacs, Diary file names a file of diary entries (any storage name) and Diary in the agenda shows them with the category Diary, in the calendar too. An entry starts at the left edge with a date (~Nov 5, 2026~, ~11/5/2026~, ~Nov 5~ every year, ~*/15~ the 15th of every month, ~Monday~ every week) or a ~%%(sexp)~ such as ~%%(diary-anniversary 11 20 1990) Anna (%d)~, ~diary-block~, ~diary-float~, ~diary-cyclic~, ~diary-date~, ~diary-remind~ or an expression using ~date~. Date style chooses American, European or ISO dates. A line that starts with a space or a tab continues the entry above it, so a note can run over several lines (the agenda joins them with a semicolon). A date alone on its line with indented events beneath it shows one agenda line for each. A time in the text, such as ~10:00am~ or ~2pm-3:30pm~, becomes the line's time. An ~&~ before a date or a sexp keeps the entry in the agenda but leaves its day unmarked in the calendar. A sexp may run over indented lines in the diary file; in an Org file it is a single line. Birthdays: Settings, Emacs, Contacts files names your contacts files, and a ~%%(org-contacts-anniversaries)~ line in the diary or in an agenda file shows each contact's birthday as ~Birthday: Jane Doe (36th)~. Birthday property changes the property read (BIRTHDAY by default); its value is a date such as ~1990-11-23~, an Org timestamp, or ~11-23~ without a year. Both layouts that org-vcard writes work: the flat one, with ~:BIRTHDAY:~ in the heading's properties, and the tree one, where a child heading with ~:FIELDTYPE: birthday~ holds the date. The calendar also lists holidays: Settings, Emacs, Holidays turns the General, Christian and Solar categories on or off (Solar lists the equinoxes and solstices, and the daylight saving changes, in your time zone), Holidays in the agenda shows them as Diary lines, and Local holidays takes your own as Emacs forms, such as ~(holiday-fixed 3 14 "Pi Day")~, ~(holiday-float 11 4 4 "Fourth Thursday")~ or ~(holiday-sexp '(if (= year 2026) (list 7 4 year)) "Sexp day")~.

View, then Agenda, lists what is scheduled, due or dated in the open files, by Day, Week, 2 weeks, Month or Year; the arrows, a swipe left or right, or f and b move through time, and a tap on a row goes to that heading. Overdue tasks show again on today ("Sched. 3x:" is three days late), deadlines show "In 3 d." as they near, and repeating tasks appear on each of their dates. Views switches to the TODO list, a tags view (a match such as ~work+urgent~) or a search for words. On a day with timed entries a time grid (8:00, 10:00 and so on, with a line for now on today) shows the free hours; Settings, Emacs, Agenda time grid turns it off.

Filter keeps some of the rows: by tag (~+work -home~), category (~+calls~), effort (~<1:00~, ~>0:30~, ~=2:00~; entries with no effort stay only for ~>~) and an Emacs regexp (~+rent~ keeps lines that match, ~-rent~ hides them). The filters show in the title and Clear all filters removes them. Mark turns a tap into a mark; All and None mark every row or none, and Act on N sets the TODO state, adds or removes a tag, sets the priority, schedules, sets a deadline or archives every marked entry. In the Text view C-c a a opens the agenda, C-c a t the TODO list, C-c a m tags and C-c a s a search.

** Capture
C-c c (or Menu, Commands, Capture) lists the capture templates by key and description. Tap one, or type its key, answer its questions, edit the text, and Save files it into the template's target; Cancel drops it.

Emacs's own template, ~t~ Task, which files a TODO under Tasks, is there until you set your own; it files to ~.notes~ in your storage, since Emacs's ~~/.notes~ has no home folder here. A template is set as ~init.el~ writes it, in Settings, Emacs, Capture templates (Reset brings the default back):

#+begin_example
(setq org-capture-templates
  '(("t" "Todo" entry (file+headline "notes.org" "Inbox")
     "* TODO %?\n")))
#+end_example

Capture templates can come from the init file (next section); ~add-to-list~ puts the newest template first, as in Emacs. Types are ~entry~, ~item~, ~checkitem~, ~table-line~ and ~plain~; targets are ~file~, ~file+headline~ (made when missing), ~file+olp~, ~file+function~, ~file+datetree~, ~file+weektree~, ~file+olp+datetree~ and the ~+prompt~ forms, which ask for the date (a date tree files under year, month and day headings it makes in order; a week tree uses ISO weeks); options are ~:prepend~, ~:empty-lines~, ~:empty-lines-before~, ~:empty-lines-after~, ~:immediate-finish~, ~:prepare-finalize~, ~:tree-type week~ or ~month~, ~:time-prompt~, ~:clock-in~, ~:clock-keep~ and ~:clock-resume~ (the clock starts with the capture, stops when it is filed, and with ~:clock-resume~ the clock it interrupted starts again). A template with only a key and a description is a group: its key opens the templates whose keys begin with it, and a menu row ~(org-capture nil "wm")~ runs a template by its key. ~file+function~ and ~:prepare-finalize~ name a function you define with ~defun~ in the same text; it finds or makes the heading (point is left on it) or tidies the captured text, using ~let~, ~setq~, ~dolist~, ~if~, ~when~, ~format~, ~re-search-forward~, ~goto-char~, ~insert~, ~replace-match~, ~flush-lines~ and the like. An ~item~ or ~checkitem~ template without a bullet gets one, and a numbered list is renumbered. Escapes: ~%^{Prompt|default}~ or ~%^{Prompt|a|b|c}~ asks, ~%\1~ repeats an answer, ~%<%Y-%m-%d>~, ~%U~, ~%T~, ~%t~, ~%u~, ~%a~ (a link to the heading you were on), ~%i~ (the selected text), ~%^T~, ~%^t~, ~%^U~ and ~%^u~ (ask for a date) and ~%?~ (where the caret starts). With no templates set, Emacs's own Task template files into ~.notes~ under Tasks.

** Init file
Settings, Emacs, Init file names a Lisp file, such as ~github:org/init.el~, that runs at startup and when you choose Reload init file in the palette. It sets Emacs's own settings with ~setq~, adds capture templates with ~add-to-list~, defines functions with ~defun~ and runs other files with ~(load "github:org/globals.el")~; an ~easy-menu-define~ form is the extra menu, opened by the ☰ button at the bottom right, opposite Back (its rows run commands, ~(org-capture nil "k")~, ~(org-agenda ...)~ or your own functions, and a row that goes to a heading keeps the view you are in); a name without a storage prefix is beside the file that loads it. What the file sets shows as Init file in Settings, Emacs and cannot be changed there.

A file runs as code, so Serita shows it first and asks Run or Skip; a file that has changed asks again. A form that fails is listed in the Init file sheet with its file and line, and the rest still runs. A setting Serita does not use yet is kept and listed there.

** Refile and archive
C-c C-w lists the places the heading can go; tap one and the heading with its subtree moves there, as its last child. C-c M-w files a copy and keeps the original. In the Outline view, a heading's actions include Refile and Archive.

Which headings are listed is set as ~init.el~ writes it, in Settings, Emacs, Refile targets:

#+begin_example
(setq org-refile-targets '((nil :maxlevel . 2) ("notes.org" :level 1))
      org-refile-use-outline-path t)
#+end_example

A target is a file (~nil~ is this one, ~org-agenda-files~ is the agenda files) with ~:maxlevel~, ~:level~, ~:tag~, ~:todo~ or ~:regexp~. ~org-refile-use-outline-path~ shows the path of each heading, ~org-reverse-note-order~ puts the subtree first instead of last, and ~org-refile-use-cache~ keeps the target list until you run Clear refile cache.

C-c C-x C-a (or C-c $) archives the subtree into the file named in Settings, Emacs, Archive location, ~%s_archive::~ unless you change it; ~::* Archived~ keeps it in the same file under a heading. The entry records when and where it came from in ARCHIVE_TIME, ARCHIVE_FILE, ARCHIVE_OLPATH and ARCHIVE_CATEGORY properties. C-c C-x A moves it under an Archive heading among its siblings, and C-c C-x a toggles the ARCHIVE tag.

** Examples
The ~examples~ folder holds a file for each area: outline, dates, clocking, capture, refile and archive, a weekly review, a project with clocking, find and replace, tables, links and footnotes, a diary, contacts with birthdays, and ~config.org~, which lists every setting with an example. The first time the app opens it offers them as sample documents, and File, Sample documents lists them later. One opens as a new tab and is saved only if you save it; follow the line at its top.

** Log settings
C-c C-z adds a note to the entry: a line ~- Note taken on [time]~ with your text under it, newest first, after the planning line and properties (inside the log drawer when one is set). The settings file's ~org-log-done~ is ~time~ or ~note~: finishing a task then adds ~CLOSED:~ and, for ~note~, a ~CLOSING NOTE~ line; leaving the done state takes ~CLOSED:~ away. ~org-log-reschedule~ and ~org-log-redeadline~ (~time~ or ~note~) leave a line such as ~Rescheduled from "[2026-11-20 Fri]" on [time]~ when a date that was set changes. A file can choose these with ~#+STARTUP:~ words: ~logdone~, ~lognotedone~, ~nologdone~, and the same for ~repeat~, ~reschedule~, ~redeadline~ and ~refile~, with ~logdrawer~ and ~nologdrawer~; they win over the settings. When ~org-log-done~ is ~note~, the closing note takes the place of a repeating task's log line. ~org-log-note-headings~ (in the init file) changes the text of each kind of line, with ~%t~, ~%T~, ~%d~, ~%D~, ~%s~, ~%S~; Settings, Emacs, Note when a clock stops asks for a note under the clock line.

The diary line ~%%(diary-sunrise-sunset)~ shows each day's sunrise and sunset, such as ~Sunrise 7:04am (EST), sunset 5:01pm (EST) at 36.0N, 78.9W (9:56 hrs daylight)~, from ~calendar-latitude~ and ~calendar-longitude~ in the init file (~calendar-location-name~ names the place). Times can differ from Emacs by a minute. ~sunrise-sunset~ in the palette says today's times; with C-u it asks for a date first. ~calendar-sunrise-sunset-month~ lists every day of the month the Calendar shows, and ~S~ (or the Sun button) in the Calendar says the times of the chosen day. All three need ~calendar-latitude~ and ~calendar-longitude~. ~calendar-time-display-form~ sets how the times read (for example ~'(24-hours ":" minutes)~). For a line of your own, ~solar-sunrise-sunset~, ~solar-time-string~, ~calendar-current-date~, ~equal~, ~when~, ~let~, ~format~, ~apply~, ~car~, ~cadr~, ~nth~, ~string-replace~ and ~replace-regexp-in-string~ work inside a ~%%(...)~ diary line.

In an Org file, a timestamp in a heading shows that heading on its day, and ~<%%(...)>~ shows it on each day the sexp holds: in the heading, in the text below it, or after ~SCHEDULED:~ or ~DEADLINE:~ (the agenda says Scheduled: or Deadline:). A time after the sexp, as in ~<%%(diary-float t 4 4) 10:00-11:00>~, gives the entry its time. The entry shows the heading as written, whatever the sexp returns; for a line of computed text, such as sun times, use a ~%%(...)~ line at the left margin.

Settings, Emacs, Log into drawer names the drawer (such as LOGBOOK) that holds the log line of a repeating task; empty leaves the line in the text. Log repeats is Time, Note or Off: Time adds the log line, Note asks for a note under it too (Skip adds the line alone and the cross leaves it out), Off records nothing when a repeating task is done.

Settings, Emacs, Archive marks done (nil, t or a keyword such as CANCELLED) marks a TODO heading done before it is archived, and Archive saves lists the properties kept on the archived entry (time, file, olpath, category, todo, itags). Refile new headings (Not allowed, Ask first or Allowed) adds New heading under… to the refile list: pick the parent and a title, and the heading is made at the end of the parent's subtree first.

** Settings
Menu, then Settings, sets up GitHub (owner, repository, branch, token) and WebDAV (address, user, password). They are kept in this browser, on this device.

The search field at the top of Settings finds any setting, whichever screen it is on: type part of its name, its Emacs variable (~org-log~, ~org-tags-column~) or a related word (shift arrow). Tap a result to change it there; you return to the results.

Emacs holds the settings that are Emacs's own, in sections: Tasks and logging, Agenda and calendar, Capture, refile and archive, Links and footnotes, Keys and editing, and Startup. When a task is done, When refiled, When rescheduled and When a deadline changes are each Off, Time or Note; with Note, a change of a date that was already set asks for a note (Skip logs the line alone, the cross logs nothing, and the new date stays). Shift-selection lets S-left and S-right select text where Org has no use for them. Appearance holds the look of the app; Debugging holds the key event log.

Export writes an Org file of your settings. Give it a passphrase to encrypt the tokens and passwords; without one they are written in plain text, so keep the file private. Import reads such a file on another device and replaces its settings.

If someone changes a file on the server before you save, you can merge the two copies, keep yours, or use theirs.

When you switch to a tab or return to the app, an open file is compared with storage: one without unsaved edits is reloaded, and one with edits says it changed, and saving then asks which copy to keep. Saves made offline are sent when you are back online; the mode line shows how many are waiting. If one clashed with a newer server copy, a list names the files and each is settled the same way.

** Updates
When a new version is ready, the message line says so. Menu, then Restart to update, switches to it; until you do, the version you have keeps running. Settings shows the installed version and, when one is waiting, the new one.

** Agenda line format
Settings, Emacs, Agenda line format takes ~org-agenda-prefix-format~ and ~org-agenda-category-icon-alist~ as ~init.el~ writes them. The fields are ~%c~ category, ~%i~ icon, ~%t~ time, ~%s~ scheduling label, ~%l~ level, ~%e~ effort, ~%b~ breadcrumbs and ~%T~ last tag.
: (setq org-agenda-prefix-format '((agenda . " %i %-12:c%?-12t% s")))
