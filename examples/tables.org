#+TITLE: Tables
# CC0 1.0: public domain. In the Text view put the cursor in a table and try TAB, RET, S-RET, M-up, M-down, M-left, M-right and C-c -; in the Outline view tap a cell. The formula sections below say which key or sheet to use.

* A table to edit
Columns line up when you press TAB, and numbers are right-aligned. TAB at the last field adds a row.
| Item   | Qty | Price |
|--------+-----+-------|
| Coffee |   2 |  9.50 |
| Tea    |  10 |  4.00 |
| Cake   |   1 | 12.25 |

* Sorting
Put the cursor in the Item column and press C-c ^ then a to sort a-z; the rows between rules are sorted. Use n for numbers and t for times; a capital letter reverses.
| Name  | Score |
|-------+-------|
| Mia   |    42 |
| Ben   |     7 |
| Chloe |   100 |

* Make a table
C-c | asks for a size such as 3x4 and makes an empty table. With text selected, C-c | turns each line into a row, split at tabs, commas or runs of spaces.

* Formulas: a column
A column formula fills every row below the first rule. Put the cursor in the table and press C-c C-c on the #+TBLFM: line, or press C-c * in a row. In the Outline view tap a cell, then Recalculate.
| Item   | Qty | Price | Total |
|--------+-----+-------+-------|
| Coffee |   2 |  9.50 |       |
| Tea    |  10 |  4.00 |       |
| Cake   |   1 | 12.25 |       |
#+TBLFM: $4=$2*$3;%.2f

* Formulas: a field and a sum
A field formula sets one cell: @5$4 is row 5, column 4. vsum adds a range, and @I..@II is everything between the first two rules.
| Item   | Qty |
|--------+-----|
| Coffee |   2 |
| Tea    |  10 |
|--------+-----|
| Total  |     |
#+TBLFM: @>$2=vsum(@I..@II)

* Recalculate: this row, the table, until stable
C-c * recalculates the row you are in. C-u C-c * recalculates the whole table. C-u C-u C-c * repeats until nothing changes, which is what you want when a formula uses the result of another. In the Outline view: tap a cell, Recalculate, then pick one.
| a | b | c |
|---+---+---|
| 1 |   |   |
| 2 |   |   |
#+TBLFM: $2=$1*2 :: $3=$2+1

* Add or change a formula
C-c = asks for a column formula such as $3=$1+$2. C-u C-c = asks for a field formula for the cell you are in. Leave the answer empty to remove it. C-c ' opens every formula of the table in one sheet: change a line, delete it to remove the formula, or add a line such as ~$4 = $3*2~, then Save and recalculate with C-u C-c C-c. In the Outline view: tap a cell, Formulas, then Add or tap a formula to edit it.
| x | y |
|---+---|
| 4 |   |
| 5 |   |

* Flags after a semicolon
;%.2f prints two decimals. ;N reads text as 0. ;T prints hours and minutes as hh:mm:ss. ;D and ;R choose degrees or radians.
| Hours | Duration |
|-------+----------|
| 1:30  |          |
| 0:45  |          |
#+TBLFM: $2=$1;T

* Which cell is this? And a quick sum
C-c ? shows the row and column of the cell, such as @2$1. C-c } toggles row and column numbers on the tables in the Outline view (the numbers you use in formulas, like @2$1). C-c { toggles formula debugging; the message says whether it is on. With it on, C-c * on a row shows the steps for each field (the formula, the fields substituted, the result) and asks Continue or Stop. C-c + sums the numbers in the column and puts the result in the kill ring so C-y pastes it.
| n |
|---|
| 3 |
| 4 |

* Names for columns and fields
A row whose first field is ! names the columns below it, so $qty and $price stand for those columns. Rows marked # are the ones recalculated. A _ row names the fields below it and a ^ row the fields above it. ;E makes an empty field nan, so a total with a missing price shows nan instead of a wrong number.
| ! | qty | price | total |
|---+-----+-------+-------|
| # |   2 |    10 |       |
| # |   1 |       |       |
#+TBLFM: $4=$qty*$price;E

* Formulas: a field starting with =
Type = and an expression in a field and press C-c C-c: the expression becomes the column's formula and the row is calculated. In the Outline view use Formulas, Add instead.
| a | b | c         |
|---+---+-----------|
| 1 | 2 | = $1+$2   |
| 3 | 4 |           |

* Formulas: another table with remote
remote(name,@row$col) reads a field of the table that has #+NAME: name above it; a range such as @1$1..@2$2 gives all its fields.
#+NAME: prices
| Coffee | 9.50 |
| Tea    | 4.00 |

| Cups | Cost |
|------+------|
|    3 |      |
#+TBLFM: $2=$1*remote(prices,@1$2)

* Formulas: parameters
A row starting with $ holds name=value parameters; rows marked # are the ones recalculated. $rate stands for 10 here.
| $ | rate=10 |       |
| # |       3 |       |
#+TBLFM: $3=$2*$rate

** Plot a table
C-c " g plots the table at the cursor (in the Outline view: tap a cell, then Plot). Options go on a #+PLOT: line directly above the table. The first row above a rule gives the series names.

#+PLOT: title:"Sales by month" ind:1 deps:(2 3) with:linespoints set:("ylabel 'units'" "grid")
| month | north | south |
|-------+-------+-------|
|     1 |     2 |     3 |
|     2 |     4 |     5 |
|     3 |     6 |     7 |

Text in the first column becomes the labels along the bottom, and bars read well with with:histograms.

#+PLOT: title:"Units" ind:1 deps:(2) with:histograms
| fruit  | units |
|--------+-------|
| apples |     5 |
| pears  |     3 |

* Recalculating every table until stable
Run ~M-x org-table-iterate-buffer-tables~ (palette: Recalculate all tables until stable). The first column depends on the second, the second on the third, so one pass is not enough: afterwards the row reads 7, 6, 5 and the echo area says "Convergence after 4 iterations".

| 1 |   |   |
#+TBLFM: $1=$2+1::$2=$3+1::$3=5

* Units in formulas
Units are names. ~usimplify~ merges them: the third column below reads 1.2 km.

| 1 km | 200 m |   |
#+TBLFM: $3=usimplify($1+$2)

Converting: ~uconv~ gives the value in the unit you name, ~utemp~ converts a temperature reading.

| Distance | In feet | Weight | In pounds | Boiling | In degF |
|----------+---------+--------+-----------+---------+---------|
| 2.5 km   |         | 10 kg  |           | 100 degC |        |
#+TBLFM: @2$2=uconv($1, ft)::@2$4=uconv($3, lb)::@2$6=utemp($5, degF)

* Heat map and surface plots
C-c " g on a table under ~#+PLOT: type:grid~ draws its numbers as colored cells; ~type:3d~ draws a surface you can drag to turn.

#+PLOT: type:grid title:"Heat"
| 1 | 2 | 3 |
| 2 | 4 | 6 |
| 3 | 6 | 9 |

#+PLOT: type:3d title:"Surface"
| 1 | 2 | 3 |
| 2 | 4 | 6 |
| 3 | 6 | 9 |

Showing the working: ~=>~ puts the formula and its value in the field.

| 3 |       |
#+TBLFM: $2=$1*2 => x

* Copy, export and import
Select from the first cell of "Apple" to the last cell of "Pear", then C-c C-x M-w copies those cells. Move to the empty row and press C-c C-x C-y to paste them. In a table, the palette's Export table shows it as csv or LaTeX, and Import table turns text such as ~a,b,c~ into a table.

| Fruit | Qty |
|-------+-----|
| Apple |   3 |
| Pear  |   5 |
|       |     |
|       |     |

C-# in a row turns the mark in its first column from blank to ~#~, then ~*~, then blank again; a table with no marks column gets one.

|   | Qty |
|---+-----|
|   |   3 |
|   |   5 |

* Rows and columns from the palette
Without Meta, open the Commands palette in a table and run ~org-table-kill-row~ to delete the row at the cursor, ~org-table-insert-row~ for a new one, ~org-table-move-row-up~ to reorder, or ~org-table-delete-column~ and ~org-table-insert-column~ for columns. With the cursor on Pear, kill the row:

| Fruit | Qty |
|-------+-----|
| Apple |   3 |
| Pear  |   5 |
