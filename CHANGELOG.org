#+TITLE: Changelog

* 0.11.1
Unit conversion in formulas: uconv(2.5 km, ft) converts (8202.0997 ft), as Org's own uconv recipe does but with no setup in your config, and utemp(100 degC, degF) gives the absolute temperature (212 degF), since uconv, like Calc's u c, treats temperatures as differences. About 90 units are known with Calc's names and sizes (distance, weight, volume, speed, pressure, energy, power, time), and a name Calc does not know stays plain text, as in Emacs.

* 0.11.0
#+PLOT: gains type:grid, a heat map of the table's numbers, and type:3d, a surface you drag to turn; Save image keeps the view you chose. Formulas understand units as Emacs does: 5 m + 3 m is 8 m, products and quotients keep their units, and usimplify(1 km + 200 m) gives 1.2 km, with the symbolic simplifier now matching Emacs on 92 more cases. Reloading a GitHub or WebDAV file asks the server whether it changed and skips the download when it has not.

* 0.10.13
New command org-table-iterate-buffer-tables (palette: Recalculate all tables until stable) recalculates every table in the file repeatedly until nothing changes, as Emacs does, and reports "Convergence after N iterations" or stops after 10. Formulas that mention the current time are no longer compared against Emacs, since the answer changes every minute. Fixes the release check that failed for 0.10.12 because plotting had no provenance entry.

* 0.10.12
C-c " g plots a table in Serita itself, no gnuplot needed. Options go on #+PLOT: lines above the table, read as Org does: ind, deps, with (lines, points, linespoints, boxes, histograms, impulses, steps, dots, filledcurves), title and set: for labels, ranges, grid and key. Series are titled from the header row. In the Outline view tap a cell, then Plot. Save image keeps the chart as SVG.

* 0.10.11
C-c { now steps through a recalculation: for each field a sheet shows how its formula was read and calculated, and you Continue or Stop (Stop keeps the fields already done). C-c } labels horizontal lines with their number and the column numbers. C-c ' lists formulas in Emacs's order. A formula defined twice, a range past the last column, ~1 2~ as a product and ~[1,5]^2~ now behave as in Emacs.

* 0.10.10
C-c ' edits all of a table's formulas in one sheet, and C-c } shows row and column numbers on Outline tables. C-c { toggles formula debugging. Formulas follow Emacs on 111 more cases: ~@+I~ targets, ranges and errors, numbers like ~1_000~ and ~1,5~, pairs, ~mod~ forms and Calc's simplifications. C-c * also applies field formulas.

* 0.10.9
Table formulas follow Emacs more closely, checked against 218 more Emacs cases. ~remote(name,@1$2)~ reads another table, a ~$~ row holds parameters, and C-c C-c in a field starting with ~=~ sets the column formula. Names Calc does not know are simplified as Calc does, with strings, ~mod~ and ~2x~ style products. C-c * works on any row, the table commands use the first ~#+TBLFM:~ line, and a formula that never settles reports it. Examples and README cover each.

* 0.10.8
Table formulas. A #+TBLFM: line under a table recalculates with C-c C-c, and C-c *, C-u C-c * and C-u C-u C-c * recalculate the row, the table, or until nothing changes. C-c = and C-u C-c = set a column or field formula, and the cell sheet's Recalculate and Formulas do the same in the Outline view. Arithmetic is exact, with fractions, other bases, dates and Lisp formulas. Keep files offline saves your GitHub and WebDAV files for offline use. Startup reads every file at once from the saved copy, and requests give up after 8 seconds. Fixes Refile in the Outline view and calendar holiday rows.

* 0.10.7
Fixes from testing the universal argument. The line that says which prefix is armed now sits above the command entry box, where it is always in view. Sorting with a function lists the key and compare functions and what each does, in the Text view prompts and, new, in the table cell menu (Sort, With a function). C-u C-u C-c C-w now goes to the refiled heading in a file that has not been saved, and opens the folds that hide it.

* 0.10.6
Fixes the release check that failed for 0.10.5: the agenda line format and universal argument code now have their provenance entries. Sorting a table with a function no longer depends on ~Object.hasOwn~, which Safari before 15.4 lacks.

* 0.10.5
Commands take a universal argument. In the Outline view the Commands palette has a C-u button that counts up and a row of digits beside it (Show all is gone, since it only listed commands that need the Text view); the Text view takes C-u and C-0 to C-9 from the keyboard. It changes refile (visit the target, go to the last refile, keep the entry, clear the cache), TAB and S-TAB (overview, startup visibility, show all, a level), the TODO keyword (the Nth, the next set), M-RET, the table rule and row keys, and C-c ^ f sorts by a function. Verified: against Emacs 30.1 with Org 9.7.11.

* 0.10.4
The agenda line follows ~org-agenda-prefix-format~ and ~org-agenda-category-icon-alist~: category, icon, time, scheduling label, level, effort, breadcrumbs and last tag, set in Settings, Emacs, Agenda line format. Phone rows use the same fields, each only as wide as its longest value on screen. Entries show inherited tags like Emacs, and same-day scheduled entries come before deadlines. Long prompts (sorting a table, the table-size question) no longer cover their own choices. Verified: against Emacs 30.1 with Org 9.7.11.

Fixes from testing 0.10.2 on a phone. A row inserted from the Outline grid now shows up, and the cell menu closes after every operation. Agenda and calendar rows line up in columns, and the Agenda button no longer flashes the Outline view. Save as asks "File ‘x’ exists; overwrite?" like Emacs, Clear refile cache is in the Outline palette, and a file reloaded in a background tab tells you when you return. The Outline view ignores Hide leading stars and indent mode, which are for the Text view.

* 0.0.2
Files can now be saved in the app's own storage with a version on every save, so a stale save is caught instead of overwriting newer text. The browser side of the app interface routes names like ~github:home.org~ to the right place and says plainly when a provider is not set up or the browser lacks a feature, instead of pretending. This is the storage groundwork the first installable release builds on.

* 0.0.1
The repository starter: an Org parser that returns your text exactly as it was, a document model whose undo restores it exactly, the storage naming used by the init files (~github:home.org~), and the interface each platform will implement. It exists so the project can live on GitHub with its license, clean-room checks and test runs from the first commit.
