#+TITLE: Roadmap

Planned work only. Phase order is in SPEC.md section 12.

* Phase 1: Foundations (in progress)
- Try the GitHub and WebDAV providers against real servers; the tests use fakes built from the documentation.
- WebDAV from a browser needs the server to allow cross-origin requests for its methods and headers; check this against your server. The native apps are not limited this way.
- WebDAV listing sends one request per folder; a large tree will be slow.
- Server errors (5xx) are reported today, not queued.
- GitHub: files over 1 MB, branch names containing a slash, and an empty repository (none are verified against the live service yet).
- Merge for very large, very different files (it asks the user to pick a side today).
- Changes made in another tab reaching ~watch~ (it covers the current tab today).
- Folder access in the browser (needs a stored folder handle; native apps do it fully).
- Incremental reparse on edit (the document model reparses fully today).
- Reopen the list of unsent clashes on demand; today it reappears at the next start or reconnect.

- Try Device files on a real Chromebook, including reopening a device file from Recents after a restart (the tests use fake file handles).
- The app interface's ~files~ picker functions overlap with the device storage; settle which one stays when the native apps are built.

* Decisions pending
- Whether LaTeX export stays after HTML, Slides and ASCII.
- What format Slides produces.
- Contacts and calendar exchange details (SPEC.md 13.6).

* Later: screen and views
- Empty folders are not shown when browsing, because storage lists files only.
- Floating buttons: a back arrow (navigation history) and the extras menu filled from the config's Menu list, once links and capture exist.
- Agenda and TODO list in the View menu, and the Find types of the guide, once those views and the Emacs regexp matcher exist.
- Keep open buffers across a reload (today the browser asks before you leave with unsaved text).
- Regex and Replace in the Find prompt.
- Emacs keys beyond the heading commands: movement and editing keys, the minibuffer, M-x, universal argument, and TAB and the M-arrows on plain text lines and tables, and god-mode for the C-c prefix.
- Statistics cookies on a heading that count TODO sub-headings, and how Emacs counts a heading's checkbox cookie (this build counts the checkboxes of its top-level items).
- What Emacs does with the folds a search opened when the search is accepted (this build leaves them open and closes them on cancel).
- Emacs is not installed in the build workspace, so the new tests are written by hand from the guide; run them against Emacs 29.3 batch before relying on details such as tag alignment, show2levels and the text shown by the children state.
- The heading title popup's three buttons, which insert at the cursor: footnote (A with a superscript 1), timer (stopwatch), and timestamp (calendar: C-c ., C-c !, C-u C-c ., S-up and S-down change it). They arrive with their features: timestamps and timers in the dates phase, footnotes in the markup phase.

* Later: Appearance
- Customize Light and Dark colors.
- Size and spacing controls for tables, once tables exist.
- Floating back arrow and an extras menu.
- Command palette so every command is always reachable.

* Later: Emacs parity to revisit
- After a search is accepted, which folds stay closed (Emacs keeps some closed, depending on the matches made while typing; ours opens the folds around the match).
- A command palette (M-x style) so every command is reachable even when its button or row is hidden.
